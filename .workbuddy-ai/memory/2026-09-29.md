# 2026-09-29 B/W Editorial Redesign

## What was done
Complete visual overhaul of the portfolio from green-accented design to pure black & white editorial aesthetic inspired by high-end fashion editorials and architectural portfolios.

### Design system changes (style.css)
- Replaced all green CSS variables (`--green`, `--green-dark`, `--green-light`, `--green-accent`, `--gradient-green`, `--shadow-green`) with pure B/W (`--black`, `--white`, `--gray-bg`, `--gray-border`, `--gray-text`)
- Added `--font-serif` (Playfair Display) and `--font-sans` (Inter) typography variables
- Removed all shadow variables except minimal `--shadow-md`/`--shadow-lg`
- Selection styled as black background with white text
- Scrollbar: 6px wide, black thumb on white track
- Loaded Playfair Display + Inter via Google Fonts in index.html

### Per-component changes
- **Navbar**: Serif logo with italic brackets, uppercase tracked links (12px, letter-spacing 2px), black mobile drawer with white text, square hamburger lines
- **Hero**: 88px Playfair Display name (split across two lines), rectangular photo frame (not circular) with grayscale filter, square B/W buttons with uppercase tracked text, no animated blobs or decorative rings
- **About**: Black inverted focus card with white text, em-dash prefixes instead of green checkmark icons, 56px serif heading
- **Skills**: B/W icon tiles (black bg, white icon → invert on hover), thin top-border reveal, uppercase card titles, light gray section background
- **Projects**: Solid black image headers (not green gradients), italic serif project abbreviations, outlined tech-stack pills with fill-on-hover, uppercase tracked labels
- **Contact**: Dark black form section, underline-only inputs (no background/border box), square SEND button with invert-on-hover, white hairline footer
- **ProjectDetails.vue**: 64px serif title, B/W technology pills, hairline bullets, B/W screenshot hover borders
- **AcroDetails.vue**: 72px serif title, all hardcoded green hex codes replaced with B/W, serif module numbers in italic

### Key design decisions
- Playfair Display 700 weight for all headings (dramatic, editorial)
- All buttons: border-radius 0 (sharp corners = architectural)
- All labels: uppercase + letter-spacing 2-3px = editorial caption feel
- Profile photo: grayscale(100%) filter to stay in B/W palette
- Hover effects: primarily inversion (black↔white) or opacity changes
- Section padding increased to 120px for more breathing room (editorial whitespace)
